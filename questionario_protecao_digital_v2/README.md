# Questionário — Proteção Digital v2

Inclui perfil inicial, 15 perguntas, resultado personalizado e conteúdo educativo sobre golpes digitais e uso responsável da IA.

## Configuração
1. Crie uma planilha no Google Sheets.
2. Abra Extensões > Apps Script.
3. Cole `google_apps_script.gs`.
4. Informe o ID da planilha em `SPREADSHEET_ID`.
5. Execute `setupSheet()` uma vez.
6. Implante como Aplicativo da Web, executando como você e permitindo acesso a qualquer pessoa.
7. Cole a URL `/exec` em `APPS_SCRIPT_URL` no `index.html`.
8. Publique o `index.html` no GitHub Pages.
